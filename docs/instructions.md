implement the UI event queue refactor as described in [ui-event-queue-refactor.md](ui-event-queue-refactor.md).

**Solution**: Separate lock-free UIEventQueue from InputState seqlock. Events consumed exactly once via PopAll().

**Scope**: ~400 lines across 11 files. Uses existing CommandQueue pattern as template.

**Key files**:
- Create: src/UIEventQueue.h/cpp
- Modify: RmlUiBridge, ThreadManager, LuaThread, main.cpp, InputState.h
