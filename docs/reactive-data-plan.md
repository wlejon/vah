     │ Reactive Data Binding System - Implementation Plan                                                                                                                                                                                │
     │                                                                                                                                                                                                                                   │
     │ Problem Statement                                                                                                                                                                                                                 │
     │                                                                                                                                                                                                                                   │
     │ Manufold-client needs to display dynamic, frequently-updating data (1-2Hz) without HTML strings in Lua code. Data is generated on worker threads but must bind to RmlUi views on the main thread. Current approaches fail due to: │
     │ - Lua VMs can't share tables across threads                                                                                                                                                                                       │
     │ - Serialization is inefficient for frequent updates                                                                                                                                                                               │
     │ - RmlUi's Lua data binding only handles first-level data                                                                                                                                                                          │
     │                                                                                                                                                                                                                                   │
     │ Solution Architecture                                                                                                                                                                                                             │
     │                                                                                                                                                                                                                                   │
     │ Data Flow:                                                                                                                                                                                                                        │
     │ [Worker Thread Lua]                                                                                                                                                                                                               │
     │   → data.bind("model_name", lua_table)                                                                                                                                                                                            │
     │   → Convert to C++ DynamicTable (vector<map<string,Variant>>)                                                                                                                                                                     │
     │   → Seqlock write                                                                                                                                                                                                                 │
     │                                                                                                                                                                                                                                   │
     │ [Main Thread - RmlUi Context]                                                                                                                                                                                                     │
     │   → Custom VariableDefinition reads from Seqlock                                                                                                                                                                                  │
     │   → RmlUi calls Get/Size/Child on-demand                                                                                                                                                                                          │
     │   → View auto-updates via DirtyVariable                                                                                                                                                                                           │
     │                                                                                                                                                                                                                                   │
     │ Key Insight: Store data in generic C++ containers, not Lua tables. RmlUi reads C++ directly via custom data variables.                                                                                                            │
     │                                                                                                                                                                                                                                   │
     │ ---                                                                                                                                                                                                                               │
     │ Components to Implement                                                                                                                                                                                                           │
     │                                                                                                                                                                                                                                   │
     │ 1. DataStore Class (src/DataStore.h/cpp)                                                                                                                                                                                          │
     │                                                                                                                                                                                                                                   │
     │ Purpose: Lock-free shared storage for dynamic data                                                                                                                                                                                │
     │                                                                                                                                                                                                                                   │
     │ Structure:                                                                                                                                                                                                                        │
     │ using DynamicValue = std::variant<int64_t, double, std::string, bool>;                                                                                                                                                            │
     │ using DynamicRow = std::unordered_map<std::string, DynamicValue>;                                                                                                                                                                 │
     │ using DynamicTable = std::vector<DynamicRow>;                                                                                                                                                                                     │
     │                                                                                                                                                                                                                                   │
     │ class DataStore {                                                                                                                                                                                                                 │
     │   std::unordered_map<std::string, Seqlock<DynamicTable>> models_;                                                                                                                                                                 │
     │                                                                                                                                                                                                                                   │
     │   void SetModel(name, DynamicTable data);  // Worker threads                                                                                                                                                                      │
     │   DynamicTable GetModel(name);             // Main thread                                                                                                                                                                         │
     │ };                                                                                                                                                                                                                                │
     │                                                                                                                                                                                                                                   │
     │ References:                                                                                                                                                                                                                       │
     │ - Existing Seqlock.h for lock-free pattern                                                                                                                                                                                        │
     │ - InputState.h for similar cross-thread data                                                                                                                                                                                      │
     │                                                                                                                                                                                                                                   │
     │ ---                                                                                                                                                                                                                               │
     │ 2. DynamicTableDef (src/DataBindings.h/cpp)                                                                                                                                                                                       │
     │                                                                                                                                                                                                                                   │
     │ Purpose: RmlUi VariableDefinition for reading C++ data                                                                                                                                                                            │
     │                                                                                                                                                                                                                                   │
     │ Implements:                                                                                                                                                                                                                       │
     │ class DynamicTableDef : public Rml::VariableDefinition {                                                                                                                                                                          │
     │   DataStore* store_;                                                                                                                                                                                                              │
     │   std::string model_name_;                                                                                                                                                                                                        │
     │                                                                                                                                                                                                                                   │
     │   bool Get(void* ptr, Variant& variant) override;                                                                                                                                                                                 │
     │   int Size(void* ptr) override;                                                                                                                                                                                                   │
     │   DataVariable Child(void* ptr, DataAddressEntry& addr) override;                                                                                                                                                                 │
     │ };                                                                                                                                                                                                                                │
     │                                                                                                                                                                                                                                   │
     │ References:                                                                                                                                                                                                                       │
     │ - D:/projects/RmlUi/Source/Lua/LuaDataModel.cpp (lines 130-250)                                                                                                                                                                   │
     │ - Shows exactly how to implement Get/Size/Child for dynamic data                                                                                                                                                                  │
     │ - Our version reads from DataStore instead of Lua stack                                                                                                                                                                           │
     │                                                                                                                                                                                                                                   │
     │ ---                                                                                                                                                                                                                               │
     │ 3. Lua API Bindings (in LuaThread.cpp)                                                                                                                                                                                            │
     │                                                                                                                                                                                                                                   │
     │ Purpose: Let worker threads populate data                                                                                                                                                                                         │
     │                                                                                                                                                                                                                                   │
     │ API:                                                                                                                                                                                                                              │
     │ -- Worker thread API                                                                                                                                                                                                              │
     │ data.bind("contacts", {                                                                                                                                                                                                           │
     │   {id=1, name="Alice", email="alice@example.com"},                                                                                                                                                                                │
     │   {id=2, name="Bob", email="bob@example.com"}                                                                                                                                                                                     │
     │ })                                                                                                                                                                                                                                │
     │                                                                                                                                                                                                                                   │
     │ data.update("contacts")  -- Marks dirty, triggers view update                                                                                                                                                                     │
     │                                                                                                                                                                                                                                   │
     │ Implementation:                                                                                                                                                                                                                   │
     │ - data.bind() converts Lua table → DynamicTable → DataStore::SetModel()                                                                                                                                                           │
     │ - data.update() sends Commands::DirtyDataModel{model_name} to main thread                                                                                                                                                         │
     │ - Recursively walk Lua table, extract primitives into DynamicRow                                                                                                                                                                  │
     │                                                                                                                                                                                                                                   │
     │ ---                                                                                                                                                                                                                               │
     │ 4. Command Integration (CommandQueue.h)                                                                                                                                                                                           │
     │                                                                                                                                                                                                                                   │
     │ Add:                                                                                                                                                                                                                              │
     │ struct BindDataModel {                                                                                                                                                                                                            │
     │   std::string model_name;                                                                                                                                                                                                         │
     │   // Data already in DataStore, just need the name                                                                                                                                                                                │
     │ };                                                                                                                                                                                                                                │
     │                                                                                                                                                                                                                                   │
     │ struct DirtyDataModel {                                                                                                                                                                                                           │
     │   std::string model_name;                                                                                                                                                                                                         │
     │ };                                                                                                                                                                                                                                │
     │                                                                                                                                                                                                                                   │
     │ Main thread handler:                                                                                                                                                                                                              │
     │ - BindDataModel: Register model with RmlUi via CreateDataModel() + BindCustomDataVariable()                                                                                                                                       │
     │ - DirtyDataModel: Call handle.DirtyVariable(name)                                                                                                                                                                                 │
     │                                                                                                                                                                                                                                   │
     │ ---                                                                                                                                                                                                                               │
     │ 5. RML Template Updates                                                                                                                                                                                                           │
     │                                                                                                                                                                                                                                   │
     │ Example: ui/sqlite_demo.rml                                                                                                                                                                                                       │
     │                                                                                                                                                                                                                                   │
     │ Before (HTML strings in Lua):                                                                                                                                                                                                     │
     │ html = '<div class="row">' .. name .. '</div>'                                                                                                                                                                                    │
     │                                                                                                                                                                                                                                   │
     │ After (pure data binding):                                                                                                                                                                                                        │
     │ <div data-model="contacts">                                                                                                                                                                                                       │
     │   <div data-for="contact : contacts">                                                                                                                                                                                             │
     │     <div class="row">                                                                                                                                                                                                             │
     │       <div class="name">{{contact.name}}</div>                                                                                                                                                                                    │
     │       <div class="email">{{contact.email}}</div>                                                                                                                                                                                  │
     │     </div>                                                                                                                                                                                                                        │
     │   </div>                                                                                                                                                                                                                          │
     │ </div>                                                                                                                                                                                                                            │
     │                                                                                                                                                                                                                                   │
     │ Lua becomes:                                                                                                                                                                                                                      │
     │ data.bind("contacts", database:query("SELECT * FROM contacts"))                                                                                                                                                                   │
     │                                                                                                                                                                                                                                   │
